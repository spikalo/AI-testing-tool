# Resultaten — Ollama LLM-test

Hier komt één JSON-bestand per afgeronde modeltest, met de naam
`llm_<model>_<JJJJMMDD-uummss>.json` (schema `ollama-llm-test/v1`).

Elk bestand bevat de modelgegevens, de scores per vaardigheid en per
moeilijkheidsgraad, de snelheidsmetingen, de gevonden faalpatronen en per opdracht de
volledige prompt, het antwoord en alle checks. Zie `../DOCUMENTATIE.md` §6.

Vergelijken doe je met `../ollama-resultaten.html`.
