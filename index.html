Elke test draait volledig in de browser, op je eigen apparaat. Resultaten die je opslaat, komen terecht in resultaten/resultaten.json in deze projectmap — kies die map ("resultaten") één keer per test via "kies resultatenmap", of gebruik de downloadknop en zet het bestand er zelf in. Voor taak C en D (cijfers/letters) kun je via "kies datasetmap" ook de map datasets in deze projectmap aanwijzen, zodat de dataset lokaal geladen wordt in plaats van via internet. Open de pagina's het liefst via start-server.cmd (dat serveert deze map op http://localhost:8080); rechtstreeks vanaf schijf openen laat Ollama de verbinding weigeren. Resultaten van de Ollama LLM-test komen als één JSON-bestand per model in de map resultaten-llm; die test heeft geen dataset nodig, maar wel een draaiende Ollama-server (zie het uitschuifbare vak met installatie-eisen op die pagina).
