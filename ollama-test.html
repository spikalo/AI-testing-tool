Installatie-eisen & opstarten — klik om uit te klappen
stap 1

Installeer Ollama

Download de installer van ollama.com/download (Windows / macOS / Linux) en doorloop de installatie. Ollama draait daarna als achtergronddienst op localhost:11434.

# controle in een terminal / PowerShell
ollama --version
stap 2

Installeer een model

Haal minstens één model binnen. Klein = snel maar zwakker; groter = trager maar sterker. Goede vergelijkingsset voor deze test:

ollama pull llama3.2:3b
ollama pull qwen2.5:7b
ollama pull gemma3:4b
stap 3

Start Ollama + het model

Start de server (meestal draait die al) en laad het model dat je wilt testen. Zolang het model geladen is, ziet deze pagina het als "draaiend model".

ollama serve
ollama run llama3.2:3b
stap 4 — belangrijk

Open deze pagina via localhost

Open je deze pagina rechtstreeks vanaf schijf, dan weigert Ollama de verbinding (CORS). Start daarom start-server.cmd in de projectmap en gebruik het adres hieronder. Handmatig kan ook, vanuit de projectmap:

python -m http.server 8080
http://localhost:8080/ollama-test.html
stap 5

Controleer de verbinding

Het bolletje rechtsboven wordt groen zodra deze pagina Ollama kan bereiken. In je browser moet dit adres "Ollama is running" tonen:

http://localhost:11434
Blijft het bolletje rood? Dan blokkeert Ollama deze pagina via CORS. Zet de omgevingsvariabele OLLAMA_ORIGINS op * en herstart Ollama.
Windows (PowerShell, daarna Ollama afsluiten via het systeemvak en opnieuw starten): setx OLLAMA_ORIGINS "*"
macOS / Linux: OLLAMA_ORIGINS="*" ollama serve

Geen model in de lijst? Voer ollama list uit; is die leeg, doe dan eerst stap 2.
Tip voor eerlijke vergelijking: de test draait altijd met temperature 0 en een vaste seed, zodat verschillen door het model komen en niet door toeval.
